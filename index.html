A few useful details

Before you start.

The full setup guide
Can I use the agents I already pay for?

Yes. IVE uses your existing Claude Code, Codex and Gemini (Antigravity CLI) logins. Model availability and usage limits come from your CLI and provider account.

What can I try in the browser?

The IVE interface with a sample project: start a task, open a terminal, answer a request and review a diff. The example replies are scripted; no coding provider runs in the demo.

Open the browser demo
What do I need to run IVE?

The Mac app needs Apple silicon, macOS 13.5 or newer, and a coding CLI you are signed in to. The terminal install works on macOS or Linux with Python 3.11+, Node.js 22.12+ and Git.

Is the iPhone app available?

It is coming soon to the App Store. You can explore the Phone view in the browser demo today. The coding agents themselves keep running on your Mac.
